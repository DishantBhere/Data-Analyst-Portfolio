## Workflow

1. **Collect** → raw dataset
2. **Clean** → nulls, duplicates, types
3. **Explore** → patterns, outliers
4. **Analyze** → KPIs, segments
5. **Visualize** → interactive dashboard
6. **Report** → insights + recommendations
